## 🔧 TROUBLESHOOTING

### Broker refuses to remove?
1. Try again with email verification
2. Send formal CCPA/GDPR request (see `templates/privacy_requests/`)
3. Document refusal with date/time
4. Escalate to legal compliance if needed

### Search results not de-indexing?
1. Wait 2-4 weeks (Google is slow)
2. Resubmit removal requests
3. Add robots.txt "noindex" to source pages
4. Create positive content to push down negative results

### Don't have confirmation numbers?
1. Check email for automated responses
2. Wait a few days for confirmation emails
3. Try removal process again if email lost
4. Screenshot confirmations for documentation
